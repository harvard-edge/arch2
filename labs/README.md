# Architecture 2.0 Empirical Data and Studies

This directory provides access to the empirical study data and artifacts supporting *Architecture 2.0: Principles of AI-Native System and Chip Design*.

7. **EDA Seed Dispersion:** Located in [`data/studies/06-eda-seed-dispersion/`](../data/studies/06-eda-seed-dispersion/).
