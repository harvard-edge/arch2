# Testbench Mutation Vacuity & LLM-as-a-Judge Bias

**Study ID:** `08-testbench-vacuity-and-judge-bias`
**Reference:** *Architecture 2.0: Principles of AI-Native System and Chip Design*
**Website:** [https://arch2.mlsysbook.ai](https://arch2.mlsysbook.ai)

---

## 1. Overview & Research Question

> **Research Question:** How severe is the vacuity gap between high testbench line coverage and actual semantic mutant kill rates, and do LLM judges exhibit confirmation bias when grading hardware from their own model family?

This study benchmarks 1,563 evaluation runs across 67,140 injected mutants in OpenHW CV32E40P and BaseJump STL, measuring dynamic line coverage versus mutation kill rate, alongside in-family versus cross-family LLM judge error rates.

## 3. Empirical Findings

- **The 55.8% Vacuity Gap:** AI-generated testbenches achieve an average of **$92.9\%$ dynamic line coverage** but kill only **$37.1\%$ of injected functional mutants**, establishing a **$55.8\%$ Vacuity Gap** where buggy hardware passes testbenches undetected.
- **Judge Confirmation Bias:** When evaluating defective RTL generated by their own model family, LLM judges falsely approve broken designs **$86.1\%$ of the time** ($2.22\times$ higher false-acceptance rate than cross-family judges).
- **Formal Verification Parity:** Formal SystemVerilog Assertions (SVA) and bounded model checking (BMC) detect 100% of injected safety violations, exposing the inadequacy of ungrounded LLM judges.

## 4. Packaged Datasets & Schema

### Primary Data File
- [`testbench_vacuity_and_judge_calibration.csv`](./testbench_vacuity_and_judge_calibration.csv)

### Data Dictionary
| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| `module_name` | `string` | Hardware target (CV32E40P ALU, Decoder, Regfile, etc.) |
| `generator_model` | `string` | Model generating the testbench or RTL |
| `judge_model` | `string` | Model evaluating the design |
| `judge_family_match` | `boolean` | True if generator and judge share same model family |
| `dynamic_line_coverage_pct`| `float` | Measured Verilator/VCS line coverage percentage |
| `mutation_kill_rate_pct` | `float` | Percentage of synthetic mutants killed by testbench |
| `vacuity_gap_pct` | `float` | Dynamic line coverage minus mutation kill rate |
| `judge_false_acceptance_pct`| `float` | False acceptance rate on defective mutant circuits |
