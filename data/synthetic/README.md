# Synthetic data — not evidence

Files in this directory contain values produced by a random number generator,
a formula, or a hand-typed table. **Nothing here is a measurement and nothing
here may be cited as evidence.**

Two kinds of file end up here. Some were *presented* as measurements and were
not; those are the serious ones, and their reader-facing claims are traced in
`FABRICATED-CLAIM-TRACE.md`. Others are constructed illustrations that were
never wrong in themselves but were filed in `data/source-receipts/`, where the
directory name made a claim the file could not support.

They are kept, rather than deleted, for one reason: figures and prose elsewhere
in this repository were built from them, and those claims cannot be traced and
withdrawn if the underlying file disappears.

Each file's first header line says so explicitly. `data/validate_provenance.py`
fails if that line is missing, and fails if any generated file reappears under
`data/source-receipts/`.

directory named *source receipts* asserts something about itself, and these could
not support it. Their plotting scripts moved with them.

Reader-facing claims derived from these files are listed in
`FABRICATED-CLAIM-TRACE.md` at the repository root, along with what replaced
each one.
