# Synthetic data — not evidence

Files in this directory contain values produced by a random number generator or
a formula. **Nothing here is a measurement and nothing here may be cited as
evidence.**

They are kept, rather than deleted, for one reason: figures and prose elsewhere
in this repository were built from them, and those claims cannot be traced and
withdrawn if the underlying file disappears.

Each file's first header line says so explicitly. `data/validate_provenance.py`
fails if that line is missing, and fails if any generated file reappears under
`data/source-receipts/`.

| File | Generated by | Real replacement |
| --- | --- | --- |
| `SYNTHETIC-testbench_vacuity_and_judge_calibration.csv` | `random.Random` / `rng.gauss` in `mine_testbench_vacuity_and_judge_bias.py` | None yet. `mine_verilog_eval_mutation_pilot.py` is a genuine Icarus harness that has never been run to completion. For transcribed literature values see `data/source-receipts/chapter7-testbench-vacuity-mutation.csv` (Herdt et al., ASPDAC 2021). |
| `SYNTHETIC-eda_seed_dispersion_qor_lottery.csv` | `_gaussian_noise()` in `mine_eda_seed_dispersion.py` | `data/studies/06-eda-seed-dispersion/openroad_gcd_placement_seed_pilot.csv` — 20 real OpenROAD seeds, pinned container, ORFS JSON parsed. |

Reader-facing claims still derived from these files are listed in
`FABRICATED-CLAIM-TRACE.md` at the repository root. They have **not** been
repaired; that is an authorial decision.
