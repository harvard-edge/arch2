# Chapter 1 Figure Inventory

Hand-authored conceptual figures (no data claims):

- `ch01-cover-map.svg`: chapter overview mapping compact intent to specification, system, evidence, and commitment.
- `fig-design-method-progression`: historical design-method shifts and the
  prospective AI-native design system. Four historical examples occupy a two-by-two
  grid above the separate research ambition. Body text is 7.92 pt at the intended
  4.8-inch print width.
- `fig-ch01-three-layers-ai-integration`: the three operational layers (point
  assistance, container-bound optimization, AI-native design system). The diagram
  stacks Layer 1 at the bottom and Layer 3 at the top; each row shows what the
  team specifies (released decisions struck through), what the system works on,
  and the feedback it receives. Evaluation fidelity remains
  separate from workflow scope; the diagram carries no numerical data.
- `fig-architecture-20-loop`: the proposed loop from generation through tool
  evaluation back to generation, with architect review.
- `fig-moonshot-prompt`: the architecture and engineering work hidden by the
  compact Lighthouse prompt. Eight domains occupy two columns above the evaluation
  loop. Body text is 7.92 pt at the intended 4.8-inch print width.
- `fig-foundation-system`: the optional learned component, current project
  state, conventional methods, tools, and checks that make up the larger
  design system.

Data figure:

- `fig-demonstration-ceiling`: Elo ratings of AlphaGo versions, generated by
  `generate_fig_demonstration_ceiling.py` from
  `data/datasets/chapter1-alphago-elo.csv` (Silver et al., Nature 2017).

Render the authored `fig-design-method-progression` and `fig-moonshot-prompt`
SVG sources with `python3 render_ch01_print_diagrams.py` from this directory.
The PDF twins preserve the native 4.8-inch width; PNG twins are 1,440 pixels wide
with 300 dpi print-density metadata. The script uses the PNG-density helper in
`generate_ch01_layers_plot.py`. No empirical data are generated by this renderer.
