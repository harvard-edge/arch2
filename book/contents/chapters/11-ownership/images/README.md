# Chapter 11 Figures

Image-backed figures currently used by the chapter:

- `ch11-cover-map.svg`: unnumbered chapter overview map (conceptual, no data).
- `fig-errata-subsystem-shares.{svg,pdf,png}`: published CPU errata by subsystem.
  Generated by `data/studies/01-silicon-errata-archaeology/plot_errata_subsystems.py`
  from that study's committed data; do not edit the image files by hand. The study
  README records the sources, the completeness checks, the rules, and the audit.

The earlier errata chart (`fig-hardware-errata-lifecycle`) was removed in the
2026-09 provenance audit: its subsystem shares came from an unvalidated keyword
classifier whose default bucket was reported as "Memory Hierarchy", and its AMD
counts were truncated to hand-entered totals. `fig-errata-subsystem-shares`
replaces it with data rebuilt from the vendor documents.
