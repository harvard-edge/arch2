# Chapter 7 Figure Inventory

Active hand-authored figures:

- `ch07-cover-map.svg`: chapter overview mapping raw signals to qualified evidence, formal bounds, proxy diagnostics, and trust calibration.
- `fig-evidence-flow`: the sequence from tool return through typed result
  qualification, a comparison or property check, scoped interpretation, and a
  recorded next step, with early repair paths for incomplete returns and
  invalid checks.
- `fig-claim-frame`: candidate, comparator, measured difference, conditions,
  uncertainty, and check limits.
- `fig-trust-calibration`: an unscaled workflow separating relevant observations,
  held-out agreement checks, and bounded proxy use; generated by
  `generate_trust_calibration.py`. No synthetic data curves are used.
- `fig-independent-checks`: shared failure assumptions versus a
  claim-specific checking path.
- `fig-sva-bmc-coverage-depth`: unscaled formal-result routing diagram for
  counterexamples, completed unbounded proofs, bounded-only results, and
  inconclusive checks; generated by `generate_sva_bmc_plot.py`.
- `fig-ch07-defect-discovery-modalities`: (a) CV32E40P v1.0.0 RTL issues by
  finding method, from the OpenHW CV32E40P User Manual verification chapter;
  (b) Herdt et al. (ASP-DAC 2021) Table 1 mutant totals. Generated by
  `data/datasets/plot_defect_discovery_matrix.py`.
- `fig-synthesis-verification-funnel`: conceptual multi-fidelity verification
  workflow; engines are examples, with no measured costs or attrition. Generated by
  `../data/plot_synthesis_verification_funnel.py`, which reads no data file.
